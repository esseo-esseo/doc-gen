# PRD: Doc-Gen Harness

## 목표
다양한 형식(md, image, pdf, text)의 입력 데이터를 받아 모던하고 가독성 높은 HTML 프레젠테이션과 Confluence 붙여넣기 문서를 자동 생성한다.

## 사용자
문서 작업이 잦은 직장인. 회의록, 기획서, 보고서를 빠르게 공식 발표 자료로 변환하고 싶은 사람.

## 핵심 기능
1. 다양한 입력(md, image, pdf, text) → 슬라이드형 HTML 프레젠테이션 생성
2. HTML 우측 상단 PDF 저장 버튼 (브라우저 인쇄 → PDF)
3. 하단 페이지네이션 (이전/다음 버튼, 점 인디케이터, 슬라이드 카운터, 키보드 ← →)
4. Confluence 에디터 직접 붙여넣기 가능한 Markdown 문서 생성 (선택)
5. 입력 자료 자동 아카이브 (사용 완료 자료 분리 보관)

## MVP 제외 사항
- 회사 로고/브랜딩 적용
- Confluence API 직접 연동
- 웹 UI / 별도 앱
- PPT(pptx) 파일 생성

## 디자인
- 로고 없음, 모던 미니멀 스타일, 가독성 최우선
- 색상: 딥 블루그레이(#1E293B) + 화이트(#FFFFFF) + 블루 액센트(#3B82F6)
- 폰트: 시스템 폰트 스택 (Segoe UI / -apple-system / Noto Sans KR)
- 슬라이드 비율: 16:9 고정
